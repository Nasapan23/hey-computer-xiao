# ESP32 Local TinyML Firmware

This is the firmware for the local-training path. It continuously runs the TinyML detector, rejects unknown-user wake attempts, and uploads the 5 seconds after an authorized wake.

It uses:

```cpp
#include "model_data.h"
```

`model_data.h` is generated by:

```powershell
python training\train_local_wake_word.py
```

Do not edit `model_data.h` by hand.

## Code Layout

```text
esp32_tinyml_wake_word/
|-- esp32_tinyml_wake_word.ino  configuration, setup, loop
|-- audio_runtime.h             microphone, buffers, rolling window
|-- tinyml_runtime.h            TFLite setup, features, inference
|-- network_client.h            Wi-Fi and HTTP requests
|-- collection_mode.h           serial data collection mode
|-- wake_detection.h            5 second post-wake audio upload
`-- model_data.h                generated by training
```

## Arduino Libraries

Install:

- Espressif ESP32 board package
- `TensorFlowLite_ESP32` or another TensorFlow Lite Micro Arduino port for ESP32

The sketch also uses ESP32-core libraries:

- `WiFi`
- `HTTPClient`
- `ESP_I2S`

## Flash Steps

1. Train locally first.
2. Confirm this file exists:

```text
esp32_tinyml_wake_word/model_data.h
```

3. Open `esp32_tinyml_wake_word.ino` in Arduino IDE.
4. Set Wi-Fi and `PC_SERVER_PING_URL`.
5. Set `PC_SERVER_UPLOAD_URL`.
6. Select XIAO ESP32S3.
7. Enable PSRAM if available.
8. Upload.
